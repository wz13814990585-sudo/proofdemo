# ProofDemo V1 威胁模型

## 资产与信任边界

受保护资产包括用户应用数据、凭据、DemoSpec/配方、浏览器录制、断言证据、提供方密钥和最终视频。信任边界存在于自然语言/提供方调用、DemoSpec/配方文件、目标 Web 源站、Playwright、FFmpeg、产物目录和本地 API 之间。

提供方输出是不可信的提议数据。DemoSpec、修复候选、配方、清单、持久化报告和媒体元数据在使用前都会重新验证。LLM 文本绝不能作为执行或验证的证明。

## 主要威胁与控制

| 威胁 | V1 控制措施 |
| --- | --- |
| 跨源导航或带凭据的 URL | 在领域层和浏览器适配器中执行严格的 HTTP 源站验证 |
| 填充轨迹/日志捕获密钥 | 无凭据契约、执行前填充策略、省略填充载荷、诊断信息脱敏 |
| 破坏性或金融点击 | 语义标记检测；每次运行/重放/修复都需要新的 `--allow-risky-actions` 批准 |
| 提供方提示词/输出滥用 | 严格结构化模型、无工具、无持久化、显式模型、确定性重新验证 |
| 跨提供方密钥误投递 | DeepSeek 显式选择、独立环境密钥、固定 DeepSeek 地址；不复用 OpenAI 密钥或 `OPENAI_BASE_URL` |
| 虚假成功声明 | 独立断言、证据、终态 `PASSED` 门禁、基于证据的旁白 |
| 路径遍历或产物替换 | 受限的解析路径、原子写入、字节数与 SHA-256 清单检查 |
| 配方/基线篡改 | 规范语义指纹、schema/profile 预检、来源哈希 |
| 媒体命令注入 | 不使用 shell 的参数数组、有界超时、固定编解码器/滤镜 |
| 资源耗尽 | 有界模型字段、场景/操作/断言数量、暂停预算、进程超时、CI 超时 |
| 浏览器诊断泄露 | 持久化前进行有界脱敏；提供方密钥只保留在环境中 |
| 探索时的跨源资源、写请求或重定向 | 全新无凭据上下文；逐请求拦截并拒绝非 GET、跨源及全部 3xx 响应；风险 URL 过滤与访问预算 |
| 模型伪造页面/控件证据 | 链接建议精确匹配安全候选，DemoSpec 导航和交互目标与实际报告逐项锚定，审批后重新核对哈希和锚定结果 |
| 润色层伪造事实或向媒体命令注入文本 | 仅从 `PASSED` 及哈希校验的源产物构造编辑计划；模型/页面文本只通过离线 Chromium 的 `textContent` 绘图，FFmpeg 滤镜仅含数值表达式；润色视频和计划均纳入清单 |

## 剩余风险

V1 在本地运行，不提供认证、凭据保管库、租户隔离、不可信网站沙箱、恶意软件扫描或保留服务。语义点击筛查无法证明不透明或误导性应用标签背后的真实效果。CSS 和应用行为仍需人工审查 DemoSpec。SHA-256 只能证明本地字节一致性，不能证明可信作者身份。外部应用状态可能在基线与重放之间发生变化。选定模型提供方与目标网站的可用性仍是按需启用功能的外部依赖。模型提供方会收到用户目标、允许的源站和有界页面观察；不要对敏感目标使用。已在聊天中暴露的密钥应撤销，不得用于真实试验。

只针对操作人员获授权访问的应用和数据运行。处理不可信目标时，应使用专用操作系统账户/容器及非生产 fixture 数据。

Stage 12 的“只读”并不证明服务器 GET 没有副作用。恶意页面还可能把秘密直接显示在标题、标签或截图中；虽然探索器不读取当前输入值、不导入凭据且不把填充值写入事件，仍不能自动识别所有页面敏感内容。探索报告与截图是本地敏感产物，不能直接发布。当前同源规则也不构成任意不可信站点的完整网络沙箱；高风险目标需要更强的外部隔离。

Stage 13 只记录 click/fill 的归一化目标坐标，不记录填充值；坐标仍可能透露界面结构。场景标题来自经过审查的 DemoSpec 而非页面观察，可能带有误导性措辞；通过标注只证明关联断言已通过，不证明产品的其他宣传主张。视频字幕和覆盖层应人工审阅后再对外发布。哈希校验防止本地产物意外或单点篡改，但没有签名或隔离机制可抵御控制同一进程和清单的攻击者。
